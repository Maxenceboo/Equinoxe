Télécharger Équinoxe

Application Android, dernière version stable.

Télécharger l'APK

Tu es sur un ordinateur ? Scanne ce code avec l'appareil photo du téléphone.

Installer en 3 étapes

  1. Ouvre le fichier téléchargé Appuie sur la notification « equinoxe.apk », ou retrouve-le dans tes Téléchargements.
  2. Android affiche un avertissement : c'est normal Équinoxe ne vient pas du Play Store, alors Android demande ton accord une seule fois.

    Pour votre sécurité, votre téléphone n'est pas autorisé à installer des applications inconnues provenant de cette source.

    AnnulerParamètres
    Appuie sur Paramètres, active Autoriser cette source, puis reviens en arrière.
  3. Appuie sur Installer Si Play Protect affiche un message, choisis Installer quand même. C'est terminé.

Les versions suivantes se font depuis l'app, avec le bouton « Mettre à jour ». Tes objectifs et ton compte sont gardés.

Sur iPhone

Pas d'App Store : Équinoxe s'installe depuis Safari, en 3 gestes.

Ouvrir Équinoxe dans Safari
  1. Ouvre le lien dans Safari Pas dans Chrome ni dans une autre app : seul Safari sait installer Équinoxe.
  2. Touche Partager, puis « Sur l'écran d'accueil » Le bouton Partager est le carré avec une flèche vers le haut, en bas de l'écran.
  3. Ouvre Équinoxe depuis son icône Dans Profil, touche Rappels pour les recevoir même app fermée. C'est terminé.

Les mises à jour arrivent toutes seules. Ton compte est le même que sur Android : tu peux changer de téléphone.
